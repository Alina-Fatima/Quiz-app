🧠 Quiz Time — Interactive Quiz App

An interactive and responsive Quiz App built with HTML, CSS, and JavaScript.
The app allows users to start a quiz, answer multiple-choice questions, track their score, view progress, and see a final result with personalized feedback.

✨ Features

🎯 Start Quiz screen

❓ Multiple-choice questions

✅ Instant visual feedback for correct answers

❌ Visual feedback for incorrect answers

📊 Live score tracking

📈 Quiz progress bar

🏆 Final score/result screen

💬 Personalized result messages based on score

🔄 Restart Quiz functionality

📱 Responsive layout for smaller screens

⚡ Dynamic answer buttons generated using JavaScript

🛠️ Technologies Used

HTML5 — Structure of the application

CSS3 — Styling, layout, responsive design, hover effects, and quiz states

JavaScript (Vanilla JS) — Quiz logic, question rendering, score calculation, DOM manipulation, events, and result handling

🎮 How It Works

Click Start Quiz.

A question and its answer choices are displayed dynamically.

Select an answer.

The selected answer is checked automatically.

The correct answer is highlighted.

Your score is updated when the selected answer is correct.

The progress bar updates as you move through the quiz.

After the last question, your final score and feedback are displayed.

Click Restart Quiz to start again.
